VELOCITY PC OPTIMIZER — WINDOWS DESKTOP STARTER

Files:
- velocity_optimizer.py: Windows desktop app
- Run Velocity.bat: double-click launcher

Requirements:
- Windows 10 or Windows 11
- Python 3.10+ installed (python.org, enable "Add Python to PATH")
- No third-party Python packages required

Run:
1. Extract the ZIP into a folder.
2. Double-click "Run Velocity.bat".
3. Open Process Cleanup, click Refresh.
4. Select only apps you recognize and want closed.
5. Read the confirmation dialog and choose Yes to request closure.

Safety:
- This app only offers a hard-coded allowlist of optional desktop applications.
- It does not kill arbitrary processes or stop Windows services.
- It does not target Windows core processes, Defender/security tools, drivers, or anti-cheat.
- Launchers, capture tools, cloud sync, and peripheral utilities may be needed for your current task. Do not close them during a game session, stream, call, upload, or while unsaved work is open.
- Windows may refuse to close an app or the app may restart itself.
- No administrator privileges are requested or required by design.
- Process closure can lose unsaved work. Always read the confirmation dialog.

Log:
- Action log is saved to %LOCALAPPDATA%\VelocityOptimizer\actions.log

This is a starter build. It does not yet implement registry tweaks or guarantee FPS gains. Benchmark your games before and after changes.
